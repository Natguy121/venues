# PartySpot — birthday venue finder

A website for finding birthday party venues in Lebanon. Filter by location, see each venue's
available dates and price per person, and browse photos right in the results.

## Features

- **112 sample venues** in 35 towns across all five regions, in 21 types: restaurants,
  rooftops, beach clubs, resorts, wineries, mountain chalets, kids' play centres,
  bowling, karaoke, escape rooms, cinemas, cooking classes, yacht charters and more.
- **Map first:** the page opens on a map of Lebanon with a price marker for every
  venue that matches your filters. Nearby venues group into clusters showing the
  count and the lowest price; tap one to zoom in, or tap a marker for a photo, the
  price and a link to the venue's details.
- **Location filtering:** pick a region (Beirut, Mount Lebanon, North, South, Bekaa)
  and then a town, or use **📍 Near me** (browser geolocation) to
  filter by distance in km and sort nearest-first.
- **More filters:** date, number of guests (checked against venue capacity), max
  price per person, venue type, kid-friendly only, and free-text search.
- **Summary cards** (24 at a time, with "Show more"): a swipeable photo gallery, price per person, guest range,
  rating and the next available dates.
- **Venue details:** a large gallery, what's included, a month calendar of available
  dates, and a price estimate for your date and guest count.
- **Shareable searches:** filters and the open venue are kept in the URL (your
  location never is).
- Responsive layout, light and dark themes, keyboard accessible.

## Running locally

Requires Node.js 20+. There are no dependencies to install.

```sh
npm start              # serves the site at http://localhost:8080
npm test               # unit tests for the filtering logic and sample data
npm run generate       # regenerate src/data/venues.js (dates start today)
npm run check:images   # check every venue photo still loads (needs internet)
```

Any static file server works too (the site is plain HTML, CSS and ES modules), so it
can be hosted on GitHub Pages, Netlify and similar hosts as-is.

## Venue data

`src/data/venues.js` is generated by `scripts/generate-venues.js`; edit the script
(towns, venue-type templates, photo lists) and run `npm run generate` instead of
editing the data file by hand. Each venue looks like this:

| Field | Description |
| --- | --- |
| `id`, `name`, `type` | identity and category (e.g. "Rooftop", "Bowling") |
| `region`, `city`, `area`, `address`, `lat`, `lng` | location; coordinates drive the distance filter |
| `pricePerPerson`, `minGuests`, `maxGuests` | pricing and capacity |
| `availability` | sorted `YYYY-MM-DD` dates the venue can be booked; past dates are hidden automatically |
| `images` | photo URLs shown in the gallery (a generated placeholder appears if one fails to load) |
| `description`, `includes`, `rating`, `kidFriendly` | details |

The sample venues are fictional, placed in real Lebanese towns with approximate
coordinates, and priced in USD. Availability covers the 180 days after the date
the data was generated, so re-run `npm run generate` to keep the dates current.

Photos are real stock photos from Unsplash, chosen to match each venue type and
loaded from Unsplash's CDN under the [Unsplash License](https://unsplash.com/license).
Because many venues share a type, some photos appear at more than one venue. If a
photo is ever removed, the site shows a placeholder for it; `npm run check:images`
lists any broken links so the IDs can be replaced in the generator. Map tiles come from
OpenStreetMap; for heavy production traffic, switch to a tile provider that allows
it (see their tile usage policy). Their availability
runs from October 2026 to early March 2027.

## Roadmap: online booking

The app is built so booking can be added without reworking the UI:

1. **Backend API.** Replace the bundled data in `src/api.js` with `fetch` calls
   (`GET /venues`, `GET /venues/:id`). The rest of the app already consumes it
   asynchronously.
2. **Bookings.** Implement `createBooking({ venueId, date, guests, contact })` in
   `src/api.js`. The server must check availability atomically so two people can't
   book the same date.
3. **Enable the UI.** Set `bookingEnabled: true` in `src/config.js`. The details
   dialog already collects the date and guest count and shows the total. Add a
   contact form and a confirmation step behind the "Book this date" button.
4. **Payments and accounts** (deposits via a payment provider, booking history,
   and a venue-owner dashboard for managing dates, prices and photos).
5. **Time slots.** Extend `availability` from dates to per-date slots if venues
   host several parties a day.
